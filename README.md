# Pocket C++ IDE

1. Create a GitHub repo and upload everything in this folder (keep `.github/workflows/compile.yml`).
2. Repo Settings → Pages → deploy from branch `main`, root.
3. Settings → Actions → General → Workflow permissions → Read and write.
4. Create a fine-grained token (Developer settings) for that repo: Contents = Read/write, Actions = Read/write.
5. Open your Pages URL on your phone → Share/Menu → Add to Home Screen.
6. Tap ⚙, enter owner, repo, branch, project folder and token. Write code, tap ▶ Run.

Add an `input.txt` file in the editor to feed stdin to your program.
